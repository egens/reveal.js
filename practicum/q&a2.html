в начало
В этом спринте вы познакомились с основами синтаксиса Java. Вам рассказали про то, что Java — объектно ориентированный язык.

Это значит, что работа любой программы на Java сводится к взаимодействию набора объектов.

Классы нужны для описания структуры объектов, созданные при помощи класса объекты называются экземплярами класса.

В Java все объекты передаются по ссылке (кроме примитивов). Это значит, что если вы измените объект внутри метода, изменения сохранятся и после его выполнения.

Старайтесь избегать "божественных классов" (God Object), которые делают всё. Лучше несколько маленьких классов с чёткими обязанностями.

Методы обеспечивают функциональность класса.

Важно помнить, что хороший метод должен делать одну вещь и делать её хорошо. Это принцип Single Responsibility из SOLID, который вы встретите позже.

Если ваш метод сложно назвать одним глаголом (например, calculateSalary или validateInput), возможно, он делает слишком много — стоит его декомпозировать.

Чистый код — это не только про работоспособность, но и про читаемость. В Java для имен принято использовать CamelCase для переменных и методов (getUserData).

Переменные — существительные (userName), методы — глаголы (findUser).

В комментариях пишите не что делает код, а почему он это делает.

Многие компании используют code style guides (например, Google Java Style). Привыкайте следовать стандартам — это упрощает работу в команде.

Эти темы — основа, на которой строится вся Java-разработка. Если что-то кажется сложным, не переживайте: чем больше практики, тем понятнее становятся принципы. А пока решим задачку — пример того, что работа разработчика иногда состоит в том, чтобы разобраться в ТЗ, а не написать сложный алгоритм. https://leetcode.com/problems/find-the-maximum-achievable-number/

Что из этого – сигнатура метода?

  1. public static void printInfo(String name, int age)
  2. printUserInfo(String name, int age)
  3. printUserInfo(String, int)
  4. (String name, int age)
  5. (String, int)
Давайте проверим, как вы усвоили теорию. Что из этого сигнатура? Правильный ответ — 3.

Два метода с одинаковой сигнатурой?

  • public static void printInfo(String name, int age) {…}
  • public static void printInfo(String city, int age) {…}
Может ли в программе быть два метода с одинаковой сигнатурой? Не может, потому что компилятор не сможет выбрать из них верный при вызове.

  • Main — меню

Поставьте + кто решил и - кто не решил. В этом спринте мы пишем небольшое консольное приложение счетчик калорий.

Вам нужно последовательно наполнить несколько классов кодом. В ТЗ есть подсказки, попробуйте без них. Алгоритмы работы приложения нужно будет написать самому.

Давайте с вами решим самую сложную задачу — подсчет максимальной серии.

На экране будет код решения. Вы можете подглядывать в него при выполнении ДЗ, но очевидно, что самостоятельная работа гораздо эффективнее для вашего обучения. 


			//Счетчик лучшей серии
			int bestSeries(int goalByStepsPerDay) {
				int currentSeries = 0;
				int finalSeries = 0;
				for (int i = 0; i < 30; i++) {
					if (days[i] >= goalByStepsPerDay) {
						currentSeries++;
						if (finalSeries < currentSeries) {
							finalSeries = currentSeries;
						}
					} else {
						currentSeries = 0;
					}
				}
				return finalSeries;
			}
