Рекурсия


		// обычная рекурсия
		public static long fact(long n) {
			if (n == 0) return 1;
			return n * fact(n - 1);
		}

		// хвостовая рекурсия
		public static long factTail(long n, long acc) {
			if (n == 1) return acc;
			return factTail(n - 1, n * acc);
		}
Хвостовая рекурсия — рекурсивный вызов должен быть самым последним в функции.

Если после рекурсивного вызова функция выполняет ещё операции (например, n * fact(n-1)) - это не хвостовая. В первом примере после расчета fact(n - 1) контроль должен вернуться к строке return n * fact(n - 1); чтобы посчитать значение и вернуть результат. Компиляторы оптимизировать такое не умеют.

Во втором примере — хвостовая. Но я лично против применения рекурсии в продакшен коде, потому что в Java это лишний оверхед на стеки, тк нет оптимизации хвостовой рекурсии.
