# otp-revealjs-slides-skill

Скилл для Claude Code, который собирает презентации на [reveal.js](https://revealjs.com) в корпоративном стиле OTP Bank (шаблон QBR) с подстрочником для докладчика. Рядом лежит готовый пример — презентация «Анализ причин ошибок» кластера Liabilities.

reveal.js подключается с [cdnjs](https://cdnjs.com/libraries/reveal.js/), поэтому ничего собирать не нужно: каждая папка с презентацией самодостаточна и открывается в браузере как есть.

## Структура

```
otp-revealjs-slides-skill/
├── example/                  # готовая презентация, собранная скиллом
│   ├── index.html            # 12 слайдов с подстрочником
│   ├── otp.css               # корпоративная тема
│   └── img/otp-logo.png
├── otp-revealjs-deck/        # сам скилл
│   ├── SKILL.md              # порядок работы, стиль, правила подстрочника и фактов
│   ├── assets/               # тема, логотип, заготовка skeleton.html
│   ├── references/
│   │   └── layouts.md        # 9 макетов слайдов с готовой разметкой
│   └── scripts/
│       ├── new_deck.sh             # новая презентация из заготовки
│       ├── extract_confluence.py   # разбор экспорта страницы Confluence (.doc)
│       ├── bar_chart.py            # столбчатая диаграмма в фирменных цветах (SVG)
│       └── check_slides.js         # скриншоты слайдов и проверка вёрстки
└── README.md
```

## Что умеет скилл

- **Собирает презентацию из любого источника:** артефакт claude.ai (в том числе типа Slides), экспорт Confluence, текст из чата или тезисы.
- **Приводит слайды к шаблону QBR:**
  - цвета `#C1FD0E`, `#9E6EC6`, `#FE7C32`, `#C8DFFC`, шрифт Montserrat;
  - титул с логотипом;
  - голубая плашка раздела, строка «Источник» и номер страницы на каждом слайде.
- **Пишет подстрочник к каждому слайду:**
  - первое лицо, по существу;
  - на первом слайде приветствие и план встречи;
  - в каждом абзаце то, чего нет на самом слайде.
- **Следит за фактами:**
  - цифры пересчитывает из исходных таблиц, а не со скриншотов диаграмм;
  - отличает «не размечено» от `not_classified`;
  - перечисляет утверждения, которые не подтверждаются источниками.
- **Проверяет вёрстку перед сдачей:**
  - ничего не вылезает за слайд и не наезжает на «Источник»;
  - заголовки помещаются в одну строку;
  - у каждого слайда есть подстрочник.

## Установка скилла

Скопируйте папку `otp-revealjs-deck` в один из каталогов скиллов Claude Code:

| Где будет доступен | Куда копировать |
|---|---|
| Во всех ваших проектах | `~/.claude/skills/otp-revealjs-deck/` |
| В конкретном репозитории, для всей команды | `<репозиторий>/.claude/skills/otp-revealjs-deck/` |

После этого Claude сам подключает скилл на запросы вроде «сделай презентацию по этой странице Confluence», «приведи слайды к шаблону» или «допиши подстрочник». Вызвать скилл явно можно командой `/otp-revealjs-deck`.

## Показ презентации

Откройте `example/index.html` в браузере. Нужен доступ к двум хостам:

| Хост | Зачем |
|---|---|
| `cdnjs.cloudflare.com` | сам reveal.js 6.0.2 |
| `fonts.googleapis.com`, `fonts.gstatic.com` | шрифт Montserrat. Без него будет Arial, вёрстка сохранится, но станет менее похожей на шаблон |

Если открывать файл напрямую (`file://`) неудобно или браузер блокирует всплывающее окно докладчика, запустите локальный сервер:

```bash
cd example && python3 -m http.server 8000   # http://localhost:8000
```

### Управление во время показа

| Клавиша / параметр | Что делает |
|---|---|
| `→` `←`, `Пробел` | листать слайды |
| `S` | окно докладчика: подстрочник, следующий слайд, таймер |
| `F` | полный экран |
| `?notes` в адресе | подстрочник прямо под слайдом |
| `?notes&print-pdf` | вид для печати в PDF вместе с подстрочником (Chrome → Печать → Сохранить как PDF) |

### Версия reveal.js

Версия указана в четырёх строках `index.html`: в двух `<link>` в `<head>` и в двух `<script>` в конце. При обновлении меняйте все четыре и сверяйтесь с файлами версии на [cdnjs](https://cdnjs.com/libraries/reveal.js/). Плагин подстрочника в 6.x лежит по пути `plugin/notes.min.js`, в 5.x путь был `plugin/notes/notes.min.js`.

## Как пользоваться скиллом

1. Дайте Claude источник:
   - ссылку на артефакт claude.ai;
   - файлы экспорта Confluence (Страница → ⋯ → Экспорт в Word);
   - текст или тезисы.
2. Скажите, в какую папку положить презентацию и для какой аудитории она.
3. Claude соберёт слайды и проверит вёрстку. В ответе он перечислит:
   - какие цифры пересчитал;
   - что решил сам;
   - какие утверждения стоит перепроверить.
4. Правки давайте обычным текстом, например: «подстрочник подлиннее, но без воды» или «замени Backend chapter на Кластер Liabilities».

Скрипты можно запускать и вручную:

```bash
bash otp-revealjs-deck/scripts/new_deck.sh my-deck
python3 -I otp-revealjs-deck/scripts/extract_confluence.py page.doc out/
python3 -I otp-revealjs-deck/scripts/bar_chart.py spec.json > chart.svg
node otp-revealjs-deck/scripts/check_slides.js my-deck/index.html out/check
```

## Зависимости

| Для чего | Что нужно |
|---|---|
| Показ | любой современный браузер и доступ к хостам из «Показа презентации» |
| `extract_confluence.py`, `bar_chart.py` | Python 3.8+, только стандартная библиотека |
| `check_slides.js` | Node.js 18+ и Playwright с Chromium (`npm i -g playwright && npx playwright install chromium`). Если cdnjs недоступен, скрипт берёт reveal.js той же версии из npm (`npm pack`) |
| Разбор шаблона `.pptx` (необязательно) | LibreOffice Impress и poppler-utils |

## Ограничения

- Ссылки `claude.ai/share/…` скилл прочитать не может. Опубликуйте разговор как артефакт или вставьте текст.
- Цвета меток (`analysis_error` и т.д.) рассчитаны на тему «классификация ошибок». Для другой темы переименуйте классы `.tag.*` в `otp.css`, палитру оставьте.
- Подстрочник и цифры — черновик. Перед выступлением их нужно прочитать и проверить.
